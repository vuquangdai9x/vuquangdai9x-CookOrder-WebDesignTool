# Exploring Non-pictographic Symbologies for Games — Lookup Summary

## Symbols as High-Density Representation
Detailed pictorial art can be expensive while communicating surprisingly little tactical information. Glyphs trade literal depiction for a compact visual language that can expose more state, support greater systemic complexity, and leave room for imagination. Once learned, a coherent symbol can become perceptually transparent to the player. The cost is an initial literacy barrier that must be designed deliberately.
→ see learned/project-horseshoe-2013-r03-non-pictographic-symbologies.md § Symbols as High-Density Representation

## Taxonomy Before Glyphs
The workflow begins by inventorying player-relevant data and organizing it into a hierarchy, then mapping the most important distinctions onto the strongest visual channels. Designing icons first produces arbitrary, overloaded marks. The data taxonomy determines which attributes need immediate pop-out, which require comparison, and which can wait for focused inspection. A glyph system is therefore an information architecture before it is an art style.
→ see learned/project-horseshoe-2013-r03-non-pictographic-symbologies.md § Taxonomy Before Glyphs

## Visual Channel Hierarchy
Color generally produces the strongest pre-attentive pop-out, followed by size, shape, and orientation, with texture and position useful under context-specific constraints. Motion, change over time, containment, topology, and interaction add further channels. Strong channels should carry high-priority distinctions and should not be reused for unrelated meanings. Accessibility requires redundancy because color, scale, motion, and cultural convention are not perceived uniformly.
